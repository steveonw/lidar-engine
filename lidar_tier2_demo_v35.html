LiDAR / Beam Evidence — Tier 2 Demo V3.5

This browser demo illustrates the interactive camera/scanner model used with the Python LiDAR engine. V3.5 adds a sensor network: six independent "eyes" (player, security cams, drone, guard, gate scanner) each with their own pose, lens, and short-term memory. Scan them individually or all at once, fuse their evidence into a combined point cloud, replay scan history, and run a guided demo. The Python engine performs the full multimodal sensing pipeline (depth, beam evidence, candidate gates, material/edge classification, contact sheets); this page is the lightweight playable Tier 2 showcase.
