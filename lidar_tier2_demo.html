LiDAR / Beam Evidence — Tier 2 Demo

This browser demo illustrates the interactive camera/scanner model used with the Python LiDAR engine. The Python engine performs the full multimodal sensing pipeline (depth, beam evidence, candidate gates, material/edge classification, contact sheets). This page is a lightweight playable Tier 2 showcase: camera poses, lens modes, scan outputs, and short-term point-cloud memory.
